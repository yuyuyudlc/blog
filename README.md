# dev.log Journal

A Next.js technical blog with a grid-driven editorial layout, markdown-backed posts, theme switching, and keyboard shortcuts.

## Structure

- `src/app`: App Router pages, layout, and global styles.
- `src/components`: Shared UI for the site shell, homepage, and article pages.
- `src/config/site.js`: Central site copy, navigation, metadata, and storage keys.
- `src/lib/posts.js`: Markdown loading and parsing helpers.
- `posts`: Markdown article content.

## Commands

```bash
npm run dev
npm run build
npm run lint
```

Open `http://localhost:3000` after starting the development server.
